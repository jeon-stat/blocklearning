# 설계: 과제 = 레시피 · 손실 조립 · 정답·입력 여러 개

목표: 처음 쓰는 사람은 지금처럼 **과제 → 데이터 → 대표 모델 → 학습**으로 바로 쓰고, 원하는 사람은 **출력·정답·손실을 직접 조립**한다.
과제는 막는 문이 아니라 **레시피(미리 맞춘 설정)** 가 된다. 기본값은 늘 학습되는 상태이고, 맞지 않는 조합은 처음부터 고를 수 없거나 빨간 상자로 알린다.

## 1. 낱말

| 낱말 | 뜻 |
|---|---|
| 정답 종류 | `class`(클래스 K개) · `value`(숫자 n개) · `seq_class`(시점마다 클래스, K × L) · `boxes`(탐지 격자) · `recon`(입력을 되살림) · `distance`(정상과의 거리) |
| 출력 머리 | 정답 종류가 정하는 마지막 층: class·value·recon → Dense, seq_class → 시점마다 1×1 Conv1D, boxes → 칸마다 1×1 Conv2D, distance → NormalDistance |
| 손실 항 | `{"term": 이름, "w": 가중치, ...설정}`. 전체 손실 = Σ w · 항 |
| 레시피 | 정답(들) + 출력 머리 + 손실 항 + 성적 · 결과 화면. 과제와 대표 모델이 채워 줌 |

## 2. 손실 항 (정답 종류마다 고를 수 있는 것만)

| 정답 종류 | 항 | 설정 |
|---|---|---|
| class | `ce` 교차 엔트로피 (기본) | `smooth` 라벨 스무딩 0–0.3, `balance` 클래스 가중치(드문 클래스를 무겁게) |
| class | `focal` Focal | `gamma` 1–5, `balance` |
| value · recon | `mse` (기본) · `mae` · `huber` | huber `delta` |
| seq_class | `ce` (기본, `balance`) · `dice` (상태마다 겹침, 짧은 구간을 덜 놓침) | |
| boxes | `det` (기본: 있음 BCE + 위치 ×5 + 클래스) | `coord`·`noobj` 무게 |
| 모든 과제 | `l2` 가중치 L2 · `l1` 가중치 L1 | |
| (중간 블록) | `act_l1` 블록 출력 L1 (희소성) | `node` 블록 id |

- 정답이 정규화된 회귀(평균 0, 표준편차 1로 맞춘 값)에서 계산한다 (지금과 같음).
- `balance`는 학습 몫의 클래스(시점) 비율로 가중치 = (전체 / (K × 그 클래스 수)), 평균이 1이 되게.
- 학습 곡선: 전체 손실과 **항마다의 값**을 함께 기록 (`progress[i].terms = {이름: 값}`).
- PyTorch(jobs.fit) · 웹 엔진(engine.js) · 내보내는 PyTorch 코드(codegen)가 같은 식. 시험으로 값이 같은지 확인.

## 3. 저장

- 학습 설정 `settings.loss = [{"term": "ce", "w": 1}, …]` (없으면 과제의 기본 = 지금 동작과 똑같음).
- 정답이 여러 개일 때는 정답 항마다 `"head": 정답 이름` (예: `{"term": "huber", "w": 1, "delta": 0.5, "head": "밸브 (%)"}`).
  정답마다 항이 하나는 있어야 하고, 가중치 L2·L1은 head 없이.

## 4. 정답 여러 개 (여러 값 동시 예측 · 분류 + 회귀)

- 과제 `multi` (multi.py). 데이터: `Dataset.extra["targets"] = [{"name", "kind": "class"|"value", "classes"}]`,
  y는 (샘플, 정답 수) 표 (분류는 클래스 번호, 값은 숫자). 값 정답만 학습 몫의 평균·표준편차로 정규화해 학습하고 출력층에 되돌림을 접음.
- 모델: 출력 블록 **하나**가 정답마다의 머리를 정해진 순서로 이어 붙인 한 줄을 냄 (`MultiOut.heads = [{"name", "kind", "classes",
  "start", "size"}]`, 분류는 클래스 수, 값은 1). 엔진·예측·저장은 지금처럼 텐서 하나를 다루고, 손실·성적·결과 화면만 머리마다 잘라 씀.
  (출력 블록을 정답마다 따로 두는 것은 그래프에 출력이 여럿인 모델이 생기면)
- 성적: 정답마다 분류 정확도·값 R², 전체는 그 평균 (`metric_name: "mean"`).
- 결과 화면: 위에 평균, 정답마다 성적 탭 → 그 정답의 혼동 행렬·산점도.
- 예시: 유압 시스템 냉각기 상태(3)·펌프 누설(3) 분류 + 밸브 %·축압기 bar 값. 내 CSV로 만드는 것은 ② 역할 표에서 (5).

## 5. 입력 여러 개 (여러 채널 시계열)

- 데이터: 같은 길이의 신호 C개 → `X`는 (n, C·L) (채널이 먼저). 길이는 채널 수를 지닌 int (`data.SeqLength`, 채널이 하나면
  그냥 int — 저장한 프로젝트·기록이 그대로 맞음). 검사·모델·계획·엔진·코드가 입력 모양을 (C, L)로 받음 (순환 모델은 (L, C)).
- 시계열 폴더: 값 열을 여러 개 고르면 채널. 구간 분할 예시: 전류 + 공압 압력 (pneumatic_seg2).
- ② 데이터의 **역할 표** (CSV): 열 이름 칩을 누르면 입력 → 정답 → 안 씀. 정답이 둘 이상이면 정답 여러 개 (열마다 분류·숫자를
  스스로 정함), 채널 수를 주면 입력 열을 채널로 나눔. 역할을 안 정했으면 지금처럼 마지막 열 = 정답, 글자뿐인 열은 안 씀.

## 6. 화면 (쉬움을 지키는 원칙)

- ④ 학습에 **손실 칩**: `손실 = [교차 엔트로피 ×1] [+]`. 칩을 누르면 항·가중치·설정, [+]는 그 정답 종류에 맞는 항만.
  레시피 그대로면 칩 하나만 보이고, 바꾸면 [레시피대로] 단추가 생김. 설명 글은 늘리지 않고 식은 [코드로 보기]에서.
- 정답이 여러 개면 칩 줄이 출력마다 하나씩.
- 결과 화면은 정답 종류가 정함 (위 4).

## 7. 순서

1. 손실 항 (출력 하나): `settings.loss`, PyTorch·엔진·코드, 손실 칩, 항마다 곡선 — 됨
2. 정답 여러 개: 데이터·출력 머리 이어 붙이기·결과 탭, 예시 (유압 시스템: 냉각기·밸브·펌프·축압기 상태를 한 번에) — 됨
3. 입력 여러 개: 채널 C, 역할 표, 예시 (구간 분할 공압 + 전류) — 됨
4. 중간 블록 항 (`act_l1`), 조립 예시 레시피
