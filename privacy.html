BlockLearning 개인정보처리방침

시행일: 2026년 11월 24일 · 서비스: https://jeon-stat.github.io/blocklearning/

BlockLearning(이하 "서비스")는 브라우저에서 블록을 이어 딥러닝 모델을 만들고 학습하는 도구입니다. 서비스에는 운영자의 서버가 없습니다. 모든 계산은 이용자의 브라우저 안에서 이루어지며, 운영자는 이용자의 데이터·프로젝트·구글 계정 정보를 받거나 보관하지 않습니다.

1. 처리하는 정보

  • 이용자가 고른 데이터 파일과 프로젝트: 이용자의 브라우저 안에서만 읽고 계산합니다. 저장은 이용자가 고른 곳에만 합니다 — 이 브라우저 안 보관함(IndexedDB) 또는 이용자 본인의 구글 드라이브.
  • 구글 계정 연결(선택): 구글 드라이브에 저장하기를 고르면, 구글 로그인 창(accounts.google.com)에서 로그인하고 서비스는 구글이 발급한 접근 토큰(약 1시간 유효)을 브라우저 메모리에만 둡니다. 비밀번호는 서비스에 전달되지 않습니다. 토큰은 저장하지 않으며, 로그아웃하거나 창을 닫으면 사라집니다.

2. 구글 사용자 데이터의 사용

  • 요청하는 권한은 https://www.googleapis.com/auth/drive.file 하나입니다. 이 권한으로는 서비스가 만든 파일과 폴더만 볼 수 있으며, 이용자의 다른 드라이브 파일·Gmail·연락처·계정 정보에는 접근할 수 없습니다.
  • 서비스는 이용자 드라이브에 BlockLearning 폴더와 프로젝트별 하위 폴더를 만들고, 그 안에 프로젝트 파일(project.dlstudio)과 데이터 사본(data.zip)을 저장·읽기·이름 바꾸기·휴지통으로 옮기기만 합니다.
  • 구글 사용자 데이터를 운영자나 제3자에게 전송·판매·공유하지 않으며, 광고·분석·모델 학습(서비스 운영자의 AI 학습 포함)에 사용하지 않습니다. 구글 API에서 받은 정보의 사용은 Google API Services User Data Policy의 제한된 사용(Limited Use) 요건을 따릅니다.

3. 외부 서비스

  • 화면과 계산 프로그램(Pyodide, TensorFlow.js), 글꼴(Pretendard)은 GitHub Pages와 jsDelivr CDN에서 받아 옵니다. 이 과정에서 이들 업체가 일반적인 접속 기록(IP 주소 등)을 남길 수 있습니다. 이용자의 데이터는 이들에게 보내지 않습니다.
  • 쿠키·광고·접속 분석 도구를 쓰지 않습니다.

4. 보관과 삭제

  • 이 브라우저 보관함의 프로젝트·라벨링 작업: 서비스의 [내 프로젝트]·라벨링 페이지의 작업 목록에서 지우거나, 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.
  • 구글 드라이브의 프로젝트: [내 프로젝트]에서 지우면 드라이브 휴지통으로 옮겨지며, 드라이브에서 영구 삭제할 수 있습니다. 서비스의 접근 권한은 구글 계정 → 서드 파티 연결에서 언제든 해제할 수 있습니다.

5. 이용 안내

교육·실험용 도구입니다. 학습 결과를 의료 진단이나 제조 판정 같은 실제 결정에 그대로 쓰지 마세요. 서비스는 있는 그대로 제공되며, 학습 결과의 정확성이나 특정 목적에의 적합성을 보장하지 않습니다. 중요한 데이터는 [내려받기]로 따로 보관하세요.

6. 문의

이 방침이나 서비스에 대한 문의는 GitHub 이슈로 남겨 주세요.

English summary

BlockLearning is provided as is, for education and experimentation; do not use its results for medical, manufacturing or other real-world decisions as they are. BlockLearning runs entirely in your browser and has no backend server. If you choose to save to Google Drive, it requests only the drive.file scope, creates a "BlockLearning" folder with one subfolder per project, and reads or writes only the files it created. Access tokens are kept in memory only. No data is sent to the operator or third parties, and Google user data is not used for advertising, analytics, or model training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
